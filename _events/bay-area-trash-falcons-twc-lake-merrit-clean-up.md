Join us for a Tech Workers Coalition Bay Area collaboration with Trash Falcons! Trash Falcons is a grassroots initiative by and for the community. Help clean up the neighborhood while getting to know each other with a 90 minute walk around Lake Merritt picking up trash. All materials, equipment, and epic Trash Falcon lore provided — the only thing required of you is showing up. Making a difference really is that easy ❤️.

We will be meeting at 400 Perkins Street, Oakland, CA, 94610 at 9:00am. The event will involve walking so if you show up late we might have moved somewhere else, so please show up on time if you can! We'll be working till 10:30am, and we ask if you want to join **please RSVP for the event [here](https://cryptpad.fr/form/#/2/form/view/2Fmha8wn56Twe2-ULk1460jm6iIbA2jRA+aUtb6HeKU/)**. This will also help us stay connected if you do end up showing up late or have to cancel!
